# اختبارات إسلامية

موقع اختبارات بسيط باللغة العربية، مربوط بـ Firebase:

- **لوحة التحكم** (الصفحة الرئيسية `/`): للمدير فقط، لإنشاء الاختبارات ومشاركتها ومتابعة النتائج وتصديرها إلى Excel.
- **صفحة الاختبار** (`/q/ABC123`): يفتحها الممتحن من الرابط المرسل له.

---

## أولًا: تجهيز Firebase (مرة واحدة فقط)

ادخل إلى [console.firebase.google.com](https://console.firebase.google.com) وافتح مشروع **nour-quiz-d0930**.

### 1) إنشاء قاعدة البيانات
1. من القائمة اختر **Firestore Database**.
2. اضغط **Create database** (إنشاء قاعدة بيانات).
3. اختر أقرب موقع لك، ثم اختر **Production mode**.

### 2) تفعيل تسجيل الدخول وإنشاء حساب المدير
1. من القائمة اختر **Authentication** ثم **Get started**.
2. من تبويب **Sign-in method** فعّل **Email/Password**.
3. من تبويب **Users** اضغط **Add user** واكتب:
   - الإيميل: `quiz@quiz.com`
   - كلمة مرور قوية تحفظها عندك.

### 3) إيقاف إنشاء حسابات جديدة (مهم للأمان)
1. في **Authentication** افتح تبويب **Settings** (الإعدادات).
2. اختر **User actions**.
3. أزل علامة الصح من **Enable create (sign-up)**.
4. اضغط **Save**.

بهذا لا يستطيع أحد إنشاء حساب جديد. (حتى لو أنشأ أحد حسابًا، فقواعد الحماية لا تعطي الصلاحية إلا للإيميل `quiz@quiz.com`).

## ثانيًا: رفع الموقع

### 1) تثبيت Node.js
نزّل نسخة **LTS** من [nodejs.org](https://nodejs.org) وثبّتها مثل أي برنامج عادي.

### 2) فتح سطر الأوامر
- **ويندوز:** ابحث في قائمة ابدأ عن `cmd` وافتحه.
- **ماك:** افتح برنامج **Terminal**.

### 3) تثبيت أدوات Firebase
اكتب هذا الأمر واضغط Enter:

```
npm install -g firebase-tools
```

> على الماك إذا ظهر خطأ صلاحيات، اكتب `sudo` قبل الأمر ثم كلمة مرور الجهاز.

### 4) تسجيل الدخول إلى حساب Google
```
firebase login
```
سيفتح المتصفح، سجّل الدخول بنفس حساب Google الذي أنشأت به المشروع.

### 5) الانتقال إلى مجلد الموقع
اكتب `cd` ثم مسافة، ثم اسحب مجلد المشروع إلى نافذة سطر الأوامر، ثم Enter. مثال:
```
cd C:\Users\Ahmad\Desktop\quiz-islam
```

### 6) الرفع
```
firebase deploy
```
هذا الأمر يرفع الموقع وقواعد الحماية معًا. عند انتهائه يظهر الرابط:

**https://nour-quiz-d0930.web.app**

افتحه وسجّل الدخول بحساب المدير. 🎉

> عند أي تعديل على الملفات لاحقًا، كرّر الخطوتين 5 و 6 فقط.

## طريقة الاستخدام باختصار

1. افتح الموقع وسجّل الدخول.
2. اضغط **إنشاء اختبار جديد**، اكتب العنوان والأسئلة، واضغط على الدائرة بجانب الإجابة الصحيحة لكل سؤال، ثم **حفظ**.
3. اضغط **مشاركة** لإرسال الرابط عبر واتساب، أو **نسخ الرابط**.
4. اضغط **النتائج** لرؤية الدرجات، والضغط على أي اسم يعرض إجاباته. ويمكن **تصدير إلى Excel**.
5. **حذف نتيجة** شخص يسمح له بإعادة الاختبار.
6. **إيقاف** الاختبار يمنع فتحه، ويمكن تفعيله مرة أخرى.

## ملفات المشروع

| الملف | الوظيفة |
|---|---|
| `public/index.html` + `public/js/admin.js` | لوحة التحكم |
| `public/quiz.html` + `public/js/quiz.js` | صفحة الممتحن |
| `public/js/config.js` | بيانات Firebase واسم الموقع وإيميل المدير |
| `public/js/common.js` | أدوات مشتركة (توحيد الأسماء، الرسائل) |
| `public/css/style.css` | التصميم |
| `firestore.rules` | قواعد الحماية |
| `firebase.json` / `.firebaserc` | إعدادات الرفع والرابط القصير `/q/...` |

### لتغيير إيميل المدير
غيّره في مكانين: `public/js/config.js` و `firestore.rules`، ثم أعد الرفع.

### ملاحظات
- الموقع يعمل على الخطة المجانية (Spark) بدون Cloud Functions.
- لأن التصحيح يتم داخل المتصفح، فالإجابات الصحيحة موجودة داخل بيانات الاختبار. هذا مناسب للاختبارات التعليمية والمسابقات الودية، وليس للامتحانات الرسمية الحساسة.
- منع التكرار يعتمد على الاسم (بعد توحيده) وعلى ذاكرة الجهاز.
